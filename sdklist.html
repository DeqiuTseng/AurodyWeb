List of Third-party SDKs

Android and iOS components used by Aurody.

Source review: November 5, 2026

This list covers the app’s configured runtime components and the resolved iOS dependencies. Build tools and test libraries are not included. Versions describe the reviewed source, and may differ from an installed build.

Interface and local-storage components are used on the device. Playback and cache components process the media or URLs you choose; network requests go to the selected source. This list does not imply that every component collects data or operates a remote service.

System frameworks and visual resources

On iOS, SwiftUI, SwiftData, AVFoundation, MediaPlayer, Network and CryptoKit provide interface, storage, playback, transfer and file processing. Android uses the platform file picker, sharing and networking APIs. These are system facilities rather than added analytics SDKs. The app’s icon sources include Ant Design Icons (MIT), project-drawn icons and developer-provided assets; attribution is retained in the source repository.

If you have a question about a component or attribution, please contact the developer.
